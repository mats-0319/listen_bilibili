# 使用手册（草稿）

这是一个听歌软件，使用B站作为音源。

首页包含视频窗口、信息展示和播放列表：

- 视频窗口：展示当前正在播放的视频（B站外链播放器宣称可以关闭弹幕，但那个参数没有生效）
- 信息展示：包括当前播放歌曲名、序号和播放列表总音乐数
- 播放列表：列举播放列表中的每一首歌，可以指定播放一首歌

离开首页（例如将应用切换到后台、进入二级页面）会暂停播放，返回时继续。

二级页面指通过主页右上角按钮进入的应用详情页，包含应用详细信息和三级页面入口

- 应用详细信息：名称、版本、开发者信息
- 三级页面入口：包括文档页面和歌单管理页面

文档页面展示使用手册（本文档）和技术说明；歌单管理页面则可以用来编辑歌单。

歌单管理页面包含顶部功能栏和展开的播放列表，你可以：

- 创建新的实例：在播放列表中增加一首歌
- 编辑一个实例：你可以在展开的播放列表的一个实例上选择编辑，修改实例信息
- 删除一个实例：你可以在展开的播放列表的一个实例上选择删除，删除这个实例
- 排序：你可以在展开的播放列表上拖动排序实例

所有修改立即生效、无法撤回。

你还可以直接编辑歌单文件：`Android/data/com.mario.listen_bilibili/files/playlist.json`，重新启动应用生效。
